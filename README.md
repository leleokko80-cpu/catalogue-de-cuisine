# Catalogue de cuisine

React (Vite) + Spring Boot 4 + MySQL 8. Java 17 required.

## Run
Backend (port 8081): `cd backend` then `.\mvnw spring-boot:run`
Frontend (port 5173): `cd frontend`, `npm install` (first time only), then `npm run dev`
MySQL: local, user `root`, password `root`. The database `recipe_catalog` is created automatically.
